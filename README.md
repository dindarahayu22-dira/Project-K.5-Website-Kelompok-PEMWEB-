# Project-K.5-Website-Kelompok-PEMWEB
Website tugas kelompok untuk mata kuliah pemrograman web.
KantinGo merupakan sistem berbasis website yang membantu mahasiswa melakukan pre-order makanan dan minuman di kantin kampus tanpa harus mengantre. Pengguna dapat melihat daftar menu dari berbagai penjual kantin, memilih makanan atau minuman, menentukan jumlah pesanan, melakukan pemesanan, dan melihat status pesanan hingga siap diambil. Penjual dapat mengelola menu dan memproses pesanan yang masuk melalui sistem.
